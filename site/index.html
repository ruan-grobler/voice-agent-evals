Voice Agent Evals: live reports

Regression tests for an AI receptionist. The same 15 caller scenarios, the same model and the same tools, run against two versions of the prompt. Only the prompt changed.

These pages are built by GitHub Actions on every push to main, by replaying the recorded calls in the repo. The recorded calls are hand-crafted scripts run through the real pipeline, not live model recordings, and every business, caller and number is fictional. Read the honesty note.
